Running the application

To run the application, you must install the libraries listed in `requirements.txt`.

[source,sh]
pip install -r requirements.txt

Download/Install Neo4j Desktop: You need a working version of 5.18+ and a database with nodes of movies, actors, directors, users and relationships.
After this step, make sure to install APOC plugin

Download/Install Postman: 
Navigate in Postman to Fetching User Question
Switch to POST and add the link ex: http://127.0.0.1:8000/api/chat
Click Body, then Raw, and JSON and add:

{
    "user_input": " (sample question)What is the highest rated movie that user_id 7 has rated in that has actor Tom Hanks?",
    "user_id": "7"
}

Then click the start button in Neo4j Desktop 
After, run this command in the python terminal:
[source,sh]
uvicorn  main:app --reload
